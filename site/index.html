WHAT IS SATOSHI HUNT?

Find public crypto puzzles. Run approved work. Earn when you solve.

Satoshi Hunt is a marketplace for publicly published computational challenges with independently verified funding. Browse real challenges, choose one to work on, run an approved worker, and receive eligible rewards through the challenge's own payout mechanism.
